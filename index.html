Cómo encontrar tu código

Solicitá el código desde la aplicación o el sitio oficial del servicio. Luego revisá la bandeja de entrada y las carpetas de spam o correo no deseado. El código se muestra únicamente en tu propio correo y debés ingresarlo directamente en el sitio oficial.

Por seguridad, este sitio no lee correos ni muestra, almacena o comparte códigos de acceso. Nunca compartas un código de verificación con otra persona.
